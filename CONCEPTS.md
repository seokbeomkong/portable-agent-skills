# Concepts

Shared domain vocabulary for this project — entities, named processes, and status concepts with project-specific meaning. Seeded with core domain vocabulary, then accretes as ce-compound and ce-compound-refresh process learnings; direct edits are fine. Glossary only, not a spec or catch-all.

## Skill portability

### Portable Skill

An Agent Skill whose shared reasoning works in both ChatGPT and Codex while host-specific tools remain conditional enhancements rather than prerequisites.

### Upstream parity

The condition in which a port retains the upstream Skill's substantive runtime behavior and assets, not merely its name, description, or a reduced approximation.

### Skill Registry

The authoritative catalog of distributable Skills, their identity, provenance, compatibility, validation, and release policy.

### Plugin Bundle

A combined Codex distribution whose Skill contents are derived from the Skill Registry and discovered through one plugin manifest.

## Relationships

A Portable Skill may claim Upstream parity. The Skill Registry governs which Portable Skills enter a Plugin Bundle and which validation and redistribution rules apply.
