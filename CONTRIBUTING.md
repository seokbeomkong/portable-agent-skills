# Contributing

Contributions are welcome when they improve a Skill actually used or evaluated for this registry.

## Pull request requirements

- Explain the use case and why a Skill is preferable to ordinary instructions.
- Include upstream repository, integrated release/commit, and license evidence for ports.
- Preserve attribution and third-party notices.
- Keep ChatGPT Web fallback behavior explicit.
- Keep Codex-only behavior conditional.
- Add or update tests for tooling changes.
- Run every command listed in the README verification section.
- Do not update an integrated revision until the adapted Skill passes review and validation.

Use conventional commit prefixes such as `feat:`, `fix:`, `docs:`, `test:`, and `chore:`.
