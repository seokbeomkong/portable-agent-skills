# Heavy Finalizer — 15 fidelity checks

원문과 윤문본을 직접 대조한다. 전체 재작성하지 말고 문제 구간만 국소 보정한다.

1. 사실·주장·수치·날짜·고유명사 보존
2. 원문 정보 누락 없음
3. 없던 주장·성과·책임·리더십 주입 없음
4. 인과·조건·시간 순서 보존
5. 직접 인용 내부 의미 보존
6. 법률·학술·기술 개념어 보존
7. 수치와 단위의 결합 보존
8. 부정/긍정·확률·확실성 반전 없음
9. 주어-행위-대상 관계 보존
10. 한정사·범위·예외 보존
11. 예시·사례의 주체와 의미 보존
12. 논리 연결 관계 보존
13. 톤 극성·평가 강도 과장 없음
14. 각주·인용 표지·번호·위치·개수 보존
15. 제목·소제목·번호 매김의 독립 구조 보존

## 자연성 역검사
- 원문에 없던 `~하였습니다`식 격식 상향
- 원문에 없던 hype/관용구
- 원문에 없던 비유·수사·문학화
- 자기소개서/경력기술서에서 참여→주도, 지원→책임, 경험→성과 같은 역할 승격

해결 불가한 fidelity 위반은 원문 구간으로 롤백하고 보고한다.
