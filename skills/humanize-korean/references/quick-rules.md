# Quick Rules — Codex standalone fast path

Upstream `epoko77-ai/im-not-ai`의 fast-path quick rules를 독립 Codex Skill용으로 정리한 슬림 룰북이다. 정의와 처방을 짧게 유지하고, 확신이 낮은 수정은 하지 않는다.

**Do-NOT:** 고유명사·제품명·모델명·기관명, 수치·날짜·단위, 직접 인용, 법률 조문, 수학·화학·통계 표기, 표준 영어 약어(LLM·GPU·MCP·API 등)는 탐지·윤문 대상에서 제외한다.

**과윤문 가드:** 변경률 30% 이상은 경고, 50% 이상은 결과 채택 금지. 가능하면 `scripts/verify_output.py`로 판정한다.

---

## A. 번역투 — S1~S2

- **A-1 [S1]** `~에 대해(서)` 남발 → 목적격 조사로 직결한다. 예: `X에 대해 논의` → `X를 논의`.
- **A-2 [S2]** `~를 통해/통하여`가 문단에서 3회 이상 반복 → 일부만 `~로`, `~해서`, `~함으로써` 등으로 분산한다. 1~2회는 보존할 수 있다.
- **A-3 [S1]** `~에 있어(서)` → `~에서` 또는 문맥에 맞는 자연스러운 절로 바꾼다.
- **A-4 [S2]** `~라는 점에서` 3회 이상 → `~서`, `~라는 이유로` 등으로 단순화한다.
- **A-5 [S2]** `~와 관련하여/관련된` → `~에`, `~의` 또는 직접 서술로 줄인다.
- **A-6 [S2]** `~에 기반하여/바탕으로` 남발 → `~로`, `~을 보고` 등으로 단순화한다.
- **A-7 [S1]** `가지고 있다` 같은 have/make/take/give+명사 직역 → 형용사·동사 중심 문장으로 환원한다. 예: `강한 경쟁력을 가지고 있다` → `경쟁력이 강하다`.
- **A-8 [S1]** 이중 피동 `~되어진다/~지게 된다` → 능동 또는 단일 피동으로 바꾼다.
- **A-9 [S2]** `~에 의해` 피동 → 행위자가 분명하면 주어로 올린다. 예: `AI에 의해 생성` → `AI가 만든`.
- **A-10 [S2]** `~할 수 있다` 남발 → 사실상 단언 가능한 곳만 직접 서술로 바꾼다.
- **A-11 [S2]** `~을 위해` 목적절 남발 → `~려고`, `~도록`, `~위한` 등으로 문맥에 맞게 분산한다.
- **A-15** 추상 주어 + 만능 동사(`보여준다/제공한다/가져온다`) 또는 영어식 사역·인지 동사 직역 → 구체 주어와 직접 서술로 환원한다.
- **A-16** `그/그녀/그것/그들`이 단락에서 3회 이상 반복되는 영어 대명사 직역 → 절반 이상 생략하거나 호칭·명사구로 바꾼다.
- **A-18** 명사 앞에 3어절 이상 긴 관형구/관계절이 몰림 → 문장을 나누거나 후치 설명으로 돌린다.
- **A-19** `~에서의/~에로의/~으로의/~에의/~으로부터의` 같은 이중 조사 → 절이나 자연스러운 구로 풀어쓴다. 단순 `~의`는 비대상이다.

## B. 영어 인용·용어 과다 — S2

- **B-1 [S2]** 한글 뒤 괄호 영어 병기가 매번 반복 → 첫 등장만 병기하고 이후는 한글 중심으로 쓴다. 표준 약어는 보존한다.
- **B-2 [S2]** 설명 없이 낀 광고성 buzzword(`seamless`, `robust`, `leverage` 등) → 광고성 표현만 자연스러운 한국어로 풀고 API·prompt·token 같은 표준 기술 용어는 유지한다.

## C. 구조적 AI 패턴 — S1~S2

- **C-2 [S2]** 칼럼·리포트에서 3개 이상 연속 불릿 블록 → 나열 자체가 의미 없으면 산문으로 통합한다.
- **C-5 [S1]** 이모지 남발 → 칼럼·리포트·공적 문서에서는 불필요한 이모지를 제거한다.
- **C-7** 문단마다 `먼저-반면-결국` 같은 3단 공식 반복 → 접속사를 줄이고 내용 흐름으로 연결한다.
- **C-8** `A인가, B인가`, `A가 아니라 B` 대구가 3회 이상 반복 → 핵심 한 번만 남기고 나머지는 비대칭 평서문이나 직접 단언으로 바꾼다.
- **C-9** `1) 2) 3)` 식 기계적 인덱싱 → 번호가 실제 구조에 필요하지 않으면 본문에 녹인다.
- **C-10** `X: Y` 콜론 부제 헤딩 반복 → 단일 명사구 헤딩으로 압축한다. 실제 학술·보고서 절 제목은 보존한다.
- **C-11 [S1]** 연결어미(`-고/-며/-지만/-면서/-아서/-어서`) 직후 불필요한 쉼표 → 제거한다.

## D. AI 특유 관용구 — S1

- **D-1** `결론적으로/따라서/이를 통해/그러므로/요약하면/정리하자면` 같은 결산어가 3회 초과 → 1~2건만 남기고 삭제·치환한다.
- **D-2** `시사하는 바가 크다/주목할 만하다/매우 중요하다` 같은 의의 과장 → 삭제하거나 이미 있는 구체 결론으로 직접 쓴다.
- **D-3** `크게 세 가지로 나눌 수 있다/다음과 같은` 같은 열거 도입 → 필요 없으면 바로 본론으로 들어간다.
- **D-4** `혁신적/획기적/압도적/파격적/폭발적/전례 없는` 등 hype 어휘가 3회 이상 → 원문에 있는 구체 사실로 환원하거나 강도를 낮춘다. 새로운 수치는 만들지 않는다.
- **D-5** `기술이 묻는다`, `시대가 부른다` 같은 의인화 추상 주어 → 장르상 필요한 수사가 아니면 사람·기관 주어나 평이한 동사로 바꾼다.
- **D-6** `~할 때입니다/~시점입니다/~할 순간입니다` 같은 결말 공식 → 구체 동사 단언으로 바꾸고 문서당 1회 이하로 제한한다.
- **D-7** `X에서 Y로/X을 넘어 Y로` 변환 공식 반복 → 직접 단언으로 바꾸고 문서당 1회 이하로 제한한다.

## E. 리듬·문장 길이 균일성 — S2

- **E-1** 모든 문장이 비슷한 길이이고 긴 문장이 전혀 없는 등 리듬이 기계적 → 의미 추가 없이 일부 문장을 짧게 끊거나 인접 문장을 자연스럽게 연결한다.
- **E-2** 동일 종결어미가 4문장 이상 연속, 또는 `~고 있다` 자동 반복 → 종결어미를 자연스럽게 다양화하고 단순 시제가 자연스러운 곳만 환원한다.
- **E-7** 해라/하게/하오/해요/합쇼 등 청자 경어법 단계가 한 문서에서 불필요하게 혼재 → 원문 주된 register 하나로 맞춘다.

## F. 과도한 수식·중복 — S2

- **F-4** `-성/-적/-화` 또는 영어 명사화의 직역이 누적 → 가능한 곳을 동사·형용사 중심으로 환원한다.
- **F-5** `전략적 함의`, `실천적 기반` 같은 `~적 N` 추상 체인이 3회 이상 → 명사+명사 또는 자연스러운 풀어쓰기로 바꾼다.

## G. 과도한 Hedging — S2

- **G-1** `~로 보인다/~로 판단된다/~라고 여겨진다/~인 듯하다` 남발 → 원문 사실이 단언을 허용하는 곳만 단언한다.
- **G-2** `~할 가능성이 있을 수 있다/~로 보여질 수 있다` 같은 이중·삼중 완곡 → 완곡 하나만 남긴다.
- **G-3** `양쪽 모두/두 가지 모두/장점도 있지만/신중하게/균형` 같은 균형 어휘가 4회 이상 반복 → 원문 근거 안에서 구체 비교나 조건부 서술로 바꾼다.

## H. 접속사 남발 — S2

- **H-1** 문두 `또한/따라서/즉/나아가/아울러/게다가/더욱이`가 5회 이상 → 다수를 제거하고 문장 자체로 흐름을 만든다.
- **H-3** `이는 ~/이 점에서/이 관점에서/이 말은` 메타 진입이 3회 이상 → 본문에 녹이거나 삭제한다.
- **H-4** `즉` 남발 → 생략하거나 필요한 경우만 자연스럽게 변주한다. 문서당 2회 이하를 기준으로 본다.

## I. 형식명사·의존명사 과다 — S2

- **I-1** `~한 것이다/~일 것이다`가 3회 이상 연속 → 일부만 직접 종결 `~다`로 바꾼다. 미래·추정 의미가 실제로 필요하면 보존한다.
- **I-2** `주목할 점은/X은 ~라는 점에 있다` 형식명사 강조 → `X는 ~다` 형태의 직접 서술로 줄인다.
- **I-3** `~다는 것이다/~다는 뜻이다` 결말 반복 → 직접 종결로 바꾸고 합산 2회 이하로 줄인다.
- **I-4** `~해야 한다/~할 필요가 있다`가 5회 이상 반복 → 원문에 주체가 있으면 주체를 살리고 구체 동사·조건문으로 변주한다.

## J. 시각 장식 남용 — S2~S3

- **J-1** 문장마다 핵심 단어를 굵게 강조 → 칼럼·리포트 본문에서는 대부분 제거한다.
- **J-2** 강조용 따옴표가 5회 이상 → 실제 인용만 남기고 평문으로 돌린다.
- **J-3** 대시(—) 부가 설명이 문장마다 반복 → 쉼표, 괄호, 별도 문장으로 분산한다. 원문에 의미 있게 쓰인 대시는 보존한다.

## 자체검증 체크리스트

1. **사실·보호구간 보존**: 고유명사·수치·날짜·단위·인용·URL·표준 기술 용어가 손상되지 않았는가.
2. **변경률**: 30% 미만인가. 30~50%면 수정 범위를 축소하고, 50% 이상이면 롤백한다.
3. **장르 보존**: 칼럼이 에세이/문학으로, 리포트가 블로그체로 변하지 않았는가.
4. **register 보존**: 격식체/구어체의 수준을 임의로 바꾸지 않았는가.
5. **잔존 S1 최소화**: 명확한 A-7/A-8/C-5/C-11/D-계열 핵심 패턴이 남지 않았는가.
6. **새 표현 주입 금지**: 원문에 없던 비유·상투구·평가·근거·숫자를 새로 만들지 않았는가.

위반이 있으면 해당 변경만 롤백하고 한 번 재수정한다. 그래도 해결되지 않으면 원문 보존을 우선한다.
